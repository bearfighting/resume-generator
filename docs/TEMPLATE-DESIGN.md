# Template Overview

Nine original layouts adapt the same resume content to different presentation styles:

1. **Modern Professional** — clear, restrained single-column chronology.
2. **Creative / Design** — expressive typography and compact skill cards.
3. **Academic / Research** — publication-friendly hierarchy and detail.
4. **Executive / Leadership** — summary-led, achievement-focused presentation.
5. **Classic / Traditional** — conventional editorial typography and flow.
6. **Two-Column / Modern** — main content with a compact right rail.
7. **Creative Minimal** — restrained accents and generous whitespace.
8. **Modern Business** — corporate hierarchy and compact skill grid.
9. **Two-Column / Left Rail** — main content with a distinct dark left rail.

## Shared features

- Sections with no included content are omitted; two-column layouts collapse when a column is empty.
- Four palettes and optional heading decorations can be selected per draft.
- Keep text selectable and readable in print. A single-column layout remains available for compatibility-oriented use.
- Do not depend on portraits, remote assets, or decorative content the user has not provided.

Design references: [MIT Career Advising](https://capd.mit.edu/resources/career-toolkit-crafting-an-effective-resume/) and [Harvard resume guide](https://careerservices.fas.harvard.edu/resources/resume-and-cover-letter-guides/).
